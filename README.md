# Lập trình cơ sở với JavaScript – Assignment 1

Website bán hàng bằng **Vanilla JavaScript**, bám theo yêu cầu Y1/Y2/Y3 của assignment WEB1044.

## Công nghệ
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Không dùng framework JavaScript

## Cấu trúc
```text
/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    ├── data.js
    ├── app.js
    ├── slider.js
    ├── cart.js
    └── form.js
```

## Chức năng đã triển khai
- Mảng sản phẩm dạng array of objects.
- 3 nhóm: sản phẩm mới, sản phẩm hot, sản phẩm khuyến mãi.
- Hiển thị sản phẩm theo danh mục.
- Hover/highlight sản phẩm.
- Slider/banner động với nút Previous/Next và dot.
- Form liên hệ có kiểm tra dữ liệu rỗng, email và số điện thoại.
- Giỏ hàng: thêm, xóa, tăng/giảm số lượng.
- Lưu giỏ hàng bằng LocalStorage, reload không mất dữ liệu.
- Countdown Flash Sale.
- Tìm kiếm sản phẩm.
- Lọc theo danh mục.
- Hiển thị tổng tiền và số lượng giỏ hàng.

## 3 yêu cầu tự đề xuất
1. **Tìm kiếm sản phẩm** – giúp khách hàng tìm sản phẩm nhanh hơn.
2. **Lọc theo danh mục** – giúp thu hẹp danh sách sản phẩm.
3. **Countdown Flash Sale** – tạo cảm giác thời gian khuyến mãi rõ ràng và hỗ trợ trải nghiệm mua hàng.

## Cách chạy
Mở `index.html` bằng trình duyệt hoặc dùng Live Server trong Visual Studio Code.

> Thông tin cá nhân của sinh viên chưa được điền vì chưa có mã SV/họ tên trong tài liệu được cung cấp. Có thể bổ sung vào báo cáo Y3 sau.
