## 4. Điểm cần nói khi bảo vệ
1. Dữ liệu sản phẩm dùng array object.
2. DOM được JavaScript render động.
3. Slider có điều khiển Previous/Next/Dots.
4. Form có validation.
5. Cart dùng LocalStorage để giữ dữ liệu sau reload.
6. Countdown dùng JavaScript timer.
7. Các chức năng mở rộng được xây thêm nhưng không thay thế yêu cầu ASM.
